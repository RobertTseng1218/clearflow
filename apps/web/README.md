# ClearFlow Frontend v1 Scaffold

這是順流 ClearFlow 第 4 輪前端最小頁面骨架，採用：
- Next.js App Router
- TypeScript
- Tailwind CSS

## 目前頁面
- `/`
- `/pricing`
- `/onboarding`
- `/dashboard`
- `/summaries`
- `/tasks`
- `/sources`
- `/settings`

## 啟動方式
```bash
npm install
npm run dev
```

## 目前狀態
- 先以 mock data 呈現畫面骨架
- 下一輪可接真實後端 API
